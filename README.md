Um pacote Python que implementa a "camada canônica" de processamento de texto: converte arquivos (EPUB/HTML/TXT/PDF) num "eixo" textual determinístico (book.body.txt), valida esse corpo contra um contrato (checks C1–C7) e gera artefatos estruturados (structure.json, chunks.jsonl, etc.). Destina-se a desenvolvedores ou pipelines que precisam de uma versão reproducível e auditável do texto fonte antes de aplicar trilhas/sistemas de análise.
